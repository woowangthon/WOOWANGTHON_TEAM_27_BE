# K-Startup API 연동 제거

2026-11-12 사용자 요청에 따라 K-Startup API 연결 코드를 전체 제거했다. 수집기·파서·단독 CLI·공개 export·전체 수집 단계와 전용 테스트/fixture를 삭제했다. 원격 push·배포·운영 피드 게시는 하지 않았다.

앱 번들에서 기존 창업지원 195건과 신규 대회 1건을 제거했다. 다른 출처 공모전 17건은 유지했다. 구버전 캐시와 원격 피드의 kstartup/contest-kstartup 출처 및 kstartup- ID도 읽을 때 제외해 다시 표시되지 않도록 한다.

DATA_GO_KR_KEY는 다른 공공데이터 API(TourAPI)도 사용하는 사용자 설정이므로 값을 삭제하거나 변경하지 않았다. 해당 키를 사용하는 K-Startup 호출 경로는 제거했다. 기존 교통·뉴스·다른 행사 수집은 유지한다.

검증: BE/FE 엄격 분석 지적 없음, FE 전체 99개 통과. BE 전체 70개 통과·기존 교통 혼잡 테스트 1개 실패이며 이 제거 작업에서 해당 사용자 엔진 정책은 바꾸지 않았다. 라이브 소스에서 K-Startup API endpoint·클래스·호출 참조가 없어졌음을 검색으로 확인했다. 남은 행사·공모전 객체가 이전 APK에서 제거 출처만 제외한 값과 정확히 같음도 비교했다. API 재수집·원격 push·배포는 실행하지 않았다.

제거 버전 `LifeRadar-1.0.1-2014.apk`를 생성하고 루트 `LifeRadar.apk`도 갱신했다. APK 내부에서 일반 행사 457건·기타 출처 공모전 17건·K-Startup 0건을 확인했다. 기존 2013과 같은 인증서, 3개 ABI, 원본 소스/번들과 빌드 사본 일치 및 인증키 미포함을 확인했다.
